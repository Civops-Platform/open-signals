# Security

open-signals is read-only: it stores nothing about callers and holds no upstream keys on the public
host. If you find a way to make it fetch a URL it shouldn't, leak a key, or exhaust an upstream on
someone else's behalf, please report it privately through GitHub's
[security advisories](https://github.com/Civops-Platform/open-signals/security/advisories/new)
rather than an issue.
